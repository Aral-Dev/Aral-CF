# ⚡ Aral CF | نصب‌کننده خودکار ورکر و دیتابیس کلودفلر

یک وب‌اپلیکیشن سریع و مرحله‌به‌مرحله با رابط کاربری فارسی که روی سرویس **Cloudflare Pages** میزبانی می‌شود. این برنامه به شما اجازه می‌دهد بدون نیاز به کار با ترمینال یا ابزار Wrangler، هرگونه اسکریپت Worker را مستقیماً از طریق لینک به اکانت کلودفلر خود اضافه کرده و در صورت نیاز دیتابیس D1 و حافظه KV را به صورت خودکار ساخته و با متغیر دلخواه به ورکر متصل (Bind) کنید.

---

## 🚀 ویژگی‌ها

- 🎨 **طراحی مرحله‌به‌مرحله (Step-by-Step Wizard):** هدایت گام‌به‌گام کاربر از ورود کلیدها تا نصب نهایی، با تم تیره و نئونی.
- 🔗 **لینک آماده API Token:** ایجاد کلید دسترسی کلودفلر با یک کلیک با دسترسی‌های از پیش تنظیم‌شده.
- 💡 **راهنمای یافتن Account ID:** آموزش دریافت شناسه اکانت از آدرس داشبورد.
- 🗄️ **یکپارچگی با پایگاه‌داده D1 و حافظه KV:** قابلیت ساخت آنی دیتابیس D1 و Namespace و اتصال (Binding) متغیر محیطی به ورکر.
- 🎲 **تولید نام تصادفی:** ایجاد اسامی مجاز برای ورکرها، دیتابیس‌ها و Namespaces بدون نیاز به تایپ دستی.
- 🛡️ **الگوهای آماده (Preset):** نصب یک‌کلیکی پروژه‌های نهان، نهان‌مینی و زئوس یا هر سورس سفارشی دیگر.
- ⚡ **بهینه‌ساز ساب‌لینک:** تزریق خودکار Fragment، Cipher Suites و ECH چندگانه به کانفیگ‌های VLESS و Trojan.
- 🧠 **آنالیز هوش مصنوعی:** استخراج تمام رشته‌های مرتبط با پراکسی از سورس ورکر با Gemini و تولید پرامپت آماده جایگزینی.
- 🤖 **ربات تلگرام:** استقرار کامل ورکر از داخل تلگرام با منوی تنظیمات تعاملی.
- 🛡️ **امنیت کامل و بدون تحریم:** استفاده از Cloudflare Pages Functions جهت دور زدن محدودیت‌های CORS بدون نگهداری کلیدهای کاربر روی سرور.

## 🛠️ راهنمای استقرار این برنامه (Setup & Deploy)

این برنامه با استفاده از **GitHub Actions** به صورت اتوماتیک بر روی Cloudflare Pages دیپلوی می‌شود.

### ۱. تنظیم سکرت‌های گیت‌هاب (GitHub Secrets)
به تنظیمات مخزن خود در گیت‌هاب بروید:
`Settings` > `Secrets and variables` > `Actions` > دکمه `New repository secret`

سکرت‌های زیر را تعریف کنید:

1. **`CLOUDFLARE_ACCOUNT_ID`**: شناسه اکانت کلودفلر شما.
2. **`CLOUDFLARE_API_TOKEN`**: یک توکن کلودفلر با دسترسی `Cloudflare Pages: Edit`.
3. **`TELEGRAM_BOT_TOKEN`** (اختیاری): توکن ربات تلگرام برای فعال‌سازی ربات نصب.
4. **`TELEGRAM_SECRET_TOKEN`** (اختیاری): یک مقدار تصادفی برای امن‌سازی وب‌هوک ربات.

> اگر سکرت‌های تلگرام را تعریف نکنید، وب‌سایت بدون ربات هم به‌طور کامل کار می‌کند.

### ۲. استقرار
- با هر بار `push` به شاخه `main` یا کلیک روی دکمه **Run workflow** در تب **Actions** گیت‌هاب، پروژه به صورت خودکار بیلد و در Cloudflare Pages منتشر می‌شود و وب‌هوک ربات تلگرام نیز ثبت می‌گردد.

## 📖 راهنمای کار برای کاربران نهایی

1. **یافتن Account ID:**  
   در داشبورد کلودفلر وارد بخش **Workers & Pages** شوید. از نوار آدرس مرورگر (URL)، بخش بین نشانی را کپی کنید:  
   `https://dash.cloudflare.com/[اینجا_شناسه_اکانت_شماست]/workers-and-pages`

2. **دریافت API Token با دسترسی‌های مورد نیاز:**  
   بر روی دکمه تعبیه‌شده در مرحله اول برنامه کلیک کنید یا از لینک مستقیم زیر استفاده نمایید (دسترسی‌های Worker، D1، KV و Account پیش‌فرض تیک خورده‌اند):  
   [ساخت API Token پیش‌تنظیم‌شده کلودفلر](https://dash.cloudflare.com/profile/api-tokens?permissionGroupKeys=%5B%7B%22key%22%3A%22workers_scripts%22%2C%22type%22%3A%22edit%22%7D%2C%7B%22key%22%3A%22d1%22%2C%22type%22%3A%22edit%22%7D%2C%7B%22key%22%3A%22workers_kv_storage%22%2C%22type%22%3A%22edit%22%7D%2C%7B%22key%22%3A%22account_settings%22%2C%22type%22%3A%22read%22%7D%2C%7B%22key%22%3A%22account_analytics%22%2C%22type%22%3A%22read%22%7D%5D&accountId=*&zoneId=all&name=Aral%20CF%20Deployer)

3. **آدرس فایل اسکریپت ورکر:**  
   لینک مستقیم Raw فایل `worker.js` را وارد کنید.

4. **اتصال D1 / KV (اختیاری):**  
   نام دیتابیس یا Namespace دلخواه و نام متغیر (مثلاً `DB` یا `KV`) را مشخص کنید تا به‌صورت خودکار ساخته و به ورکر متصل شود.

## 🧩 ساختار پروژه

```
├── public/
│   └── index.html          # رابط کاربری کامل (ویزارد، بهینه‌ساز ساب، آنالیز AI)
├── functions/
│   ├── _core.js            # موتور استقرار و مبهم‌ساز کد
│   └── api/
│       ├── deploy.js       # POST /api/deploy  → نصب/آپدیت ورکر
│       ├── analyze.js      # POST /api/analyze → آنالیز سورس با Gemini
│       ├── sub.js          # GET  /api/sub     → بهینه‌سازی ساب‌لینک
│       ├── raw.js          # GET  /api/raw     → پراکسی فایل‌های Raw
│       └── telegram-bot.js # POST /api/telegram-bot → وب‌هوک ربات
└── .github/workflows/
    └── deploy.yml          # دیپلوی خودکار روی Cloudflare Pages
```
